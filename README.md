# GitHub API Playground

Just playing around with the GitHub API.

An experimental frontend for exploring GitHub's REST API. It currently experiments with:

- Public GitHub profile lookups
- Public repository lookups
- GitHub user search

This is the "frick around with the GitHub API until an idea happens" phase.

I'm learning what the REST API exposes, what I can do with it, and how far I can push it. Once I've poked around enough, I'll turn this into an actual project.

Shouldn't take me too long to figure it out, hopefully.
